# ReInPS

ReInPS is an experimental PlayStation 2 static recompilation and compatibility project based on [PS2Recomp](https://github.com/ran-j/PS2Recomp).

The project aims to improve reusable PS2 recompilation and runtime compatibility, using **Sly Cooper** as the first major game target.

## Goals

- Improve static recompilation of PlayStation 2 EE/R5900 code.
- Expand reusable HLE and runtime support for common PS2 systems.
- Improve compatibility with DMA, GIF, GS, VIF, VU, IOP services, input, audio and filesystem behavior.
- Keep generic PS2 compatibility work separate from game-specific implementations where possible.
- Progress toward native PC execution of supported PS2 games.

## Status

ReInPS is in an early experimental stage and is not currently a complete PlayStation 2 compatibility solution or a finished PC port of Sly Cooper.

## Upstream

ReInPS is based on [ran-j/PS2Recomp](https://github.com/ran-j/PS2Recomp) and keeps the upstream project available for synchronization and comparison.

## Legal

ReInPS does not distribute PlayStation 2 BIOS files, copyrighted game executables, disc images, or original game assets.

Users are responsible for providing any legally obtained game data required for their own use.
